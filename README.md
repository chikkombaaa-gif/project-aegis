Personal portfolio — bold, clear, recruiter-ready.

**Live:** [vbarathportfolio.vercel.app](https://vbarathportfolio.vercel.app/)

## Stack

- React 19 + TypeScript + Vite 6
- Tailwind CSS v4
- Framer Motion

## Run

```bash
npm install
npm run dev
npm run build
```

Edit content in `src/data/content.ts`.
